# Generated Study Plans

Each CSV is a saved response from one Planning API request. Files are snapshots
from the time they were generated; older files can contain topics that are no
longer present in the active certification catalog. Generate a new plan to see
the current catalog and agent behavior. After a new plan is saved, the API
attempts to keep the 100 most recent matching generated plan files by deleting
older ones. Cleanup is best-effort if an old file is locked or otherwise cannot
be removed. A removed file's download URL returns not found.
