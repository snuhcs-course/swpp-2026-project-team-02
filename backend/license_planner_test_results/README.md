# License Planner Test Results

The checked-in result and trace files are snapshots from an earlier planner
implementation. Some traces include the removed readiness tool and do not
describe the current Agent tool sequence. Do not treat them as verification of
the current code.

To refresh the live API cases, run `python run_license_planner_test_cases.py`
from `backend/`. This calls Gemini and writes current schedules and traces here.
