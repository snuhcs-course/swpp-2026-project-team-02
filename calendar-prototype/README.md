# 라이센스 플래너 로컬 프로토타입

`index.html`을 브라우저에서 열면 실행됩니다. 설치나 빌드가 필요하지 않습니다.

- 왼쪽 위 메뉴에서 정보처리기사·SQLD 계획을 각각 활성화/비활성화할 수 있습니다. 비활성화한 계획은 학습 일정·시험일·검색·충돌 계산에서 제외되고, 다시 켜면 기록과 함께 복원됩니다. 기존 캘린더 일정은 계속 표시됩니다.
- 계획 목록은 앱 화면 왼쪽에서 밀려 나오는 사이드 메뉴입니다. 메뉴 바깥이나 닫기 버튼, Escape로 부드럽게 닫힙니다. 움직임 줄이기 설정을 지원합니다.
- 사이드 메뉴에서 년·월·주·일 보기를 선택할 수 있습니다. 년 보기는 12개 미니 달력이며 월 제목은 월 보기, 날짜는 일 보기로 연결됩니다. 주·일 보기는 24시간 시간표이며 겹치는 일정은 나란히 표시합니다. 이전·다음 버튼은 선택한 보기 단위로 이동합니다.
- 모든 보기에서 계획 활성화 설정과 시험일 표시가 적용되고, 학습 일정 상세·결과 기록을 공유합니다. 월·주·일 보기의 학습 일정은 기존 이동 미리보기 및 시험일 제한을 따릅니다.
- 주·일 시간표에서 학습 일정을 위아래로 드래그하면 15분 단위로 시간이 바뀌고, 주 보기에서 좌우로 드래그하면 날짜도 바뀝니다. 학습 길이는 유지되며, 위·아래 가장자리에서 시간표가 자동 스크롤됩니다. 손을 놓으면 변경 전후 날짜·시간을 표시하고, ‘확인’할 때만 반영합니다. ‘취소’하면 원래 일정을 유지합니다.
- 일·주·월 보기에서 일정을 드래그하며 좌우 가장자리 영역에 0.8초 머무르면 이전·다음 일/주/월로 페이지를 전환합니다. 계속 머무르면 반복 전환하며, 영역을 벗어나거나 손을 놓으면 대기가 취소됩니다. 드래그와 시간표 스크롤 위치를 유지하고, 취소하면 원래 페이지로 돌아갑니다. 과거·시험일 이후 페이지를 볼 수 있으나 해당 날짜로 이동은 확정할 수 없습니다.
- 가장자리 페이지 전환에는 0.32초 슬라이드 효과를 적용합니다. 다음 페이지는 오른쪽에서, 이전 페이지는 왼쪽에서 들어옵니다. 실제 날짜의 드롭 판정과 드래그는 유지하며, 움직임 줄이기 설정에서는 애니메이션을 생략합니다.
- 월 보기에서 날짜 이동을 확인한 후 다른 일정과 시간이 겹치면 시간 수정을 묻습니다. ‘확인’하면 이동한 날짜의 일 보기에서 해당 일정이 드래그 수정 준비 상태로 표시됩니다. ‘취소’하면 이미 이동한 날짜와 시간을 그대로 유지합니다. 시간 수정도 다시 드래그 후 확인해야 반영됩니다.
- 상단 ‘?’ 버튼은 일정 표시와 사용법 도움말을 엽니다. 계획의 시험일에 따라 이동 마감일을 개별 적용합니다(기사 11/30, SQLD 12/3). 새로고침하면 두 계획이 모두 활성화된 예시 상태로 돌아갑니다.

- 2026년 11월 25일 기준의 예시 달력
- 학습 일정 클릭 → 학습 내용 및 시간 확인 → 결과 선택 → 달력에 색상 반영
- 다 했어요: 초록 / 일부 했어요: 노랑 / 못 했어요: 빨강
- 미래·미확인: 어두운 회색 / 기존 일정: 회색 대각선 줄무늬
- 충돌: 원래 상태 색상 유지 + 좌측 상단 느낌표 (기존 일정 또는 다른 학습 일정과 시간이 겹치면 자동 판정). 이동 확인 후에도 판정하며, 겹치는 학습 일정 양쪽에 표시합니다.
- 충돌 일정 상세의 최상단에 안내와 ‘직접 수정하기’, ‘자동 수정하기’를 표시합니다. 직접 수정은 월 보기에서 해당 일정을 이동 준비 상태로 엽니다. 날짜를 누르거나 깜빡이는 일정을 드래그한 뒤 ‘확인’해야 반영됩니다. 자동 수정은 학습 길이를 유지하고 7일 이내 08:00–22:00의 다음 빈 시간을 15분 단위로 찾아 이동합니다. 자동 수정은 기존 일정과 다른 학습 일정 모두 피합니다.
- ‘직접 수정하기’로 시작한 이동은 취소·확인 후 해당 일정 상세로 돌아갑니다. 취소하면 기존 날짜·시간, 확인하면 변경된 날짜·시간을 표시합니다. 달력에서 바로 시작한 이동은 달력에 남습니다.
- ‘자동 수정하기’도 월 보기의 깜빡이는 제안 일정과 변경 전후 날짜·시간을 보여줍니다. ‘적용하기’를 누르면 변경된 상세 화면으로, ‘취소’를 누르면 기존 상세 화면으로 돌아갑니다. 빈 시간이 없으면 상세 화면에서 안내합니다.
- 충돌 예시: 24일 오답 정리 ↔ 수업, 26일 모의 시험 ↔ 팀 회의, 27일 이론 복습 ↔ 병원 방문, 28일 기출 풀이 ↔ 가족 모임.
- 충돌 안내의 X는 시간을 유지한 채 해당 충돌을 해제합니다. 이후 일정의 시간이나 겹치는 일정이 달라지면 충돌을 다시 판정합니다.
- ‘자동 수정하기’는 변경 전후 날짜·시간을 먼저 보여줍니다. ‘적용하기’를 눌러야 변경되고, ‘취소’나 제안 창의 X 또는 Escape는 기존 일정을 유지합니다.
- 24일까지의 학습 기록에는 검정 12% 필터 적용
- 디자인 미리보기 모드: 변경은 현재 페이지를 보고 있는 동안만 유지됩니다. 새로고침하면 충돌, 진행률, 상태, 시간 변경, 추가 일정까지 모두 최초 예시로 초기화됩니다. 예전 브라우저 저장값도 읽지 않습니다.
- 학습 내용과 학습 결과 선택 영역 사이에 진행률 막대와 직접 입력 가능한 퍼센트 수치를 항상 표시합니다. 0–100%를 1% 단위로 조절합니다.
- ‘다 했어요’는 100%, ‘못 했어요’는 0%로 이동합니다. 진행률을 조절해도 100%는 완료, 0%는 미진행, 1–99%는 일부 학습으로 자동 선택됩니다. ‘일부 했어요’를 누르면 기존의 1–99% 값을 유지하고, 끝점에서 전환한 경우 50%로 설정합니다. 미확인 일정은 최초에는 0%와 미확인 상태로 표시하며, 조작하면 결과가 기록됩니다.
- 이전·다음 달, 오늘 이동, 검색, 날짜별 목록, 학습 일정 추가 지원
- 달력의 학습 일정을 드래그하는 동안 날짜 위에 올리면 깜빡이는 이동 미리보기와 화면 아래 절반의 상세 일정을 즉시 표시합니다. 다른 날짜 위로 움직이면 상세 일정과 충돌 안내도 바로 바뀝니다. 드래그 중에는 취소·확인을 숨기고, 유효한 날짜에서 손을 놓으면 원래 날짜를 포함해 취소·확인을 선택할 수 있습니다. ‘확인’을 눌러야 날짜가 바뀌며, ‘취소’·창 바깥·Escape는 원래 일정을 유지합니다. 날짜 밖에서 놓으면 이동하지 않습니다. 원래 날짜에서 확인하면 기존 상태를 유지합니다. 시간·학습 결과는 유지하고 충돌은 다시 판정합니다. 기존 캘린더 일정은 이동할 수 없습니다.
- 마우스와 터치 드래그를 지원합니다. 키보드로는 학습 일정에 포커스한 뒤 M → 방향키 → Enter로 미리보기를 열 수 있습니다. 이동 미리보기 중에는 움직임 줄이기 설정을 존중합니다.
- 미리보기의 깜빡이는 일정은 다시 드래그할 수 있습니다. 한 번 누른 다음 다른 날짜를 눌러 다시 제안받는 것도 가능합니다. 재이동 중에도 상세 일정은 갱신되며, 취소하면 처음 이동하기 전 상태로 돌아갑니다.
- 예시 시험일은 2026-11-30이며 달력에 ‘시험일’로 표시합니다. 학습 일정은 오늘(예시 기준 2026-11-25)부터 시험일 당일까지 이동할 수 있습니다.
- 과거 날짜와 시험일 다음 날짜는 이동 미리보기 중 흐리게 표시합니다. 해당 날짜의 상세 일정은 계속 볼 수 있고, 빨간 이동 불가 안내와 함께 ‘확인’만 회색으로 비활성화됩니다. 다른 날짜를 누르거나 재드래그해 다시 선택할 수 있습니다.
- 과거 학습 기록은 클릭해서 상세 내용을 볼 수 있으나 드래그·키보드 이동 및 날짜·시간 수정은 불가능합니다. 상세 화면의 직접·자동 수정 버튼도 숨깁니다.
- 직접 수정에는 같은 날짜 범위를 적용하며, 자동 수정도 시험일 이후를 제안하지 않습니다. 시험일은 `app.js`의 `EXAM_DATE`에서 변경할 수 있습니다.
- 상세 화면에서 결과 버튼은 방향키로도 선택 가능. Escape는 달력으로 돌아가기.
- 데스크톱 오른쪽의 ‘예시 데이터 초기화’로 기본 상태 복원 가능

- 월 보기의 이동 후 충돌 안내를 통해 일 보기에서 시간을 수정한 경우, ‘확인’과 ‘취소’ 모두 월 보기로 돌아옵니다. 확인은 새 시간을 적용하고, 취소는 이미 이동한 날짜와 수정 전 시간을 유지합니다.
- 일 보기에서 바로 시작한 시간 수정은 ‘확인’과 ‘취소’ 모두 일 보기를 유지합니다. 월 보기에서 넘어온 수정이 끝난 후 새로 시작한 일 보기 수정에도 이 규칙을 적용합니다.

- 일·주 보기의 이동 미리보기는 드래그 중 작은 하단 안내로 표시하며, 상세 일정 목록 대신 시간표의 겹치는 일정과 이동 예정 일정에 빨간 느낌표를 표시합니다. 손을 놓으면 작은 패널에서 변경 전후 시간과 취소·확인을 선택합니다. 월 보기의 상세 일정 미리보기는 유지합니다.

- 시간 충돌 안내, 도움말, 일정 추가·수정 팝업은 핸드폰 화면 안에 맞춰 표시하며, 배경도 핸드폰 영역만 어둡게 처리합니다. 긴 내용은 팝업 안에서 스크롤합니다.
- 팝업과 어두운 배경은 부드럽게 나타나고 사라집니다. 핸드폰 안의 어두운 배경 클릭·닫기·취소·Escape로 닫을 수 있으며, 움직임 줄이기 설정에서는 애니메이션 없이 동작합니다.
- 팝업이 열린 동안과 닫힘 애니메이션 중에는 뒤쪽 달력의 클릭·키보드 조작·스크롤을 잠급니다. 팝업 내부는 스크롤할 수 있으며, 완전히 닫히면 기존 달력 조작 상태로 복원합니다.

- 월·주·일 보기의 시험일 표시 또는 사이드 메뉴의 ‘시험일 변경’을 눌러 계획별 시험 날짜를 수정합니다. 확인하면 달력 표시와 학습 일정 이동 마감일이 함께 바뀝니다. 기존 학습 일정은 이동하지 않으며, 시험일 뒤에 남는 일정이 있으면 변경 창에서 개수를 안내합니다. 취소·배경 클릭은 변경하지 않고, 새로고침하면 기본 시험일로 돌아옵니다.
- 시험일을 변경하면 해당 계획의 남은 학습 일정을 조정할지 묻습니다. ‘변경 예정 보기’를 누르면 월 달력에서 조정 대상의 기존 위치를 숨기고, 변경 후 날짜에 일정을 깜빡이게 표시합니다. 시간 겹침은 달력의 느낌표로 표시하며, 좌우 화살표로 다른 달도 확인할 수 있습니다. 하단의 ‘확인’을 눌러야 실제 학습 날짜가 바뀌며, ‘취소’·Escape는 원래 일정과 보기로 돌아갑니다. 초기 안내의 ‘그대로 두기’·배경 클릭도 새 시험일과 기존 학습 일정을 유지합니다. 새 기간에 비례해 날짜 간격을 조정하며, 과거 기록·완료한 학습·다른 계획은 제외하고 시간·진행률은 유지합니다. 시험일이 오늘보다 이전이면 조정을 제안할 수 없다고 안내합니다.

- 학습 일정 변경 미리보기의 깜빡이는 일정은 마우스·터치 드래그로 다시 배치할 수 있습니다. 손을 놓으면 기본 상태와 같은 이동 미리보기에서 ‘취소·확인’을 선택합니다. 확인은 해당 이동만 변경 예정 데이터에 반영하고, 취소는 해당 이동을 버린 뒤 둘 다 전체 변경 예정 미리보기로 돌아갑니다. 실제 학습 일정은 전체 미리보기의 마지막 ‘확인’ 때 함께 변경합니다. 과거·새 시험일 이후 날짜에는 놓을 수 없고, 가장자리 머무르기로 다른 달에도 옮길 수 있습니다. 전체 미리보기 하단의 ‘취소’는 수동 조정까지 모두 버립니다.
