기준: `iteration-3-pr4-base` `66e1221`의 release APK(`app-live-release.apk`, [Actions run 41016125574](https://github.com/snuhcs-course/swpp-2026-project-team-02/actions/runs/41016125574))와 배포 서버 `http://swpp26t02.147-46-242-174.sslip.io/api/v1`.

평가자에게는 각 과제의 "평가자 과제"만 전달합니다. 기대 결과는 팀 내부 검증 기준입니다.

| 항목 | 값 |

## 과제 1. 새 계획 만들기

**평가자 과제:** "11월 25일에 컴활 2급 필기 시험을 봅니다. 엑셀 기본 기능은 알지만 함수와 차트는 자신이 없어요. 평일 저녁과 토요일 오전에 공부할 수 있습니다. 앱으로 공부 계획을 만들어 보세요."

**기대 결과**

- 문항 결과는 "5문항 중 3문항 정답"이고, 단원 점수는 스프레드시트 기본 2/2, 함수와 데이터 관리 1/2, 차트와 분석 0/1
- 생성 중에는 "계획을 만드는 중이에요" 안내가 보이고, 앱이 꺼지지 않음
- 11/4~11/24 월·수·금·토에만 일정이 있고, 입력한 시간 안에서 서로 겹치지 않음
- 차트와 분석, 함수 쪽 시간이 스프레드시트 기본보다 많음
- 2분(120초) 안에 완료. 걸린 시간을 기록

## 과제 2. 만든 계획 다시 열기

**평가자 과제:** "앱을 완전히 껐다가 다시 켜서, 방금 만든 계획을 다시 찾아보세요."

**기대 결과**

- 계획 목록에 "이 기기에 저장한 계획이에요. 앱을 다시 열어도 남아 있어요." 문구와 "계획 1 · 컴퓨터활용능력 2급"이 보임
- 계획을 열면 과제 1과 같은 일정이 보임
- 서버를 재시작한 뒤에도 같고, 조정도 됨 (10/30 준우 님 확인 완료, 토요일에 한 번 더 확인)

**주의:** 앱을 삭제 후 재설치하거나 앱 데이터를 지우면 저장된 계획이 사라집니다. 검증 중 재설치했다면 과제 1부터 다시 합니다.

## 과제 3. 놓친 공부 일정 다시 잡기

**평가자 과제:** "첫 번째 공부 일정을 못 지켰습니다. 이 일정을 다른 시간으로 옮겨 보세요."

**기대 결과**

- 계획 조정에서 첫 공부 일정을 고르면 "계획이 조정됐어요"가 보이고, 옮긴 일정이 있는 주가 표시됨
- 옮긴 일정은 공부 가능 요일·시간 안에 있고 다른 일정과 겹치지 않음
- 앱을 재실행한 뒤에도 조정 결과가 남아 있음

## 과제 4. 실패하고 다시 시도하기

**평가자 과제:** "계획을 만드는 도중에 비행기 모드를 켜 보세요. 그다음 비행기 모드를 끄고 계획을 완성해 보세요."

**기대 결과**

- "계획을 만들지 못했어요"와 "서버에 연결할 수 없어요…" 안내가 보이고, 앱이 꺼지지 않음
- "입력한 내용은 그대로 있어요" 문구와 "다시 시도", "입력 수정하기" 버튼이 보임
- 비행기 모드를 끄고 "다시 시도"를 누르면 입력을 다시 하지 않고도 계획이 만들어짐

**팀 내부 추가 확인** (평가자에게는 주지 않음)

| 상황 | 입력 | 기대 결과 |
| --- | --- | --- |
| 공부 요일 없음 | 모든 요일 0시간 | "공부할 요일을 하나 이상 선택해 주세요."가 보이고 다음으로 진행 안 됨 |
| 자정 넘김 | 금 23:00 시작, 2시간 | "끝나는 시간이 자정을 넘어요…"가 보이고 진행 안 됨 |
| 날짜 순서 오류 | 시험일을 준비 시작일보다 앞으로 | "시험일은 준비 시작일보다 뒤여야 해요."가 보임 |
| 시간 부족 | 준비 시작일 11/4, 시험일 11/6, 토요일만 30분 (기간 안에 토요일 없음) | "계획을 만들지 못했어요"와 "시험일 전까지 공부할 시간이 부족해요." 안내가 보이고, "입력 수정하기"로 돌아가 고칠 수 있음 |
| 조정 중 네트워크 끊김 | 조정 중 비행기 모드 | "조정 결과를 확인할 수 없어요. 서버에 반영되었을 수 있으니 최신 계획을 불러와 확인해 주세요."가 보이고, 네트워크를 켠 뒤 최신 계획을 불러올 수 있음 |

## 검증할 때 확인할 점

- 최신 Actions APK를 실제 기기에 설치하고, 와이파이를 끄고 LTE로 확인합니다.
- 과제 1 → 2 → 3 → 4 순서로 확인합니다.
