기대 결과는 `02_he_cases.md`를 따릅니다.

## 결론

입력값 기준 과제 1~4와 팀 내부 확인 5개가 실제 기기·외부망(5G/LTE)에서 모두 끝까지 동작했습니다. 다만 일정 조정 요청이 간헐적으로 HTTP 307로 실패해 다시 시도를 약 4번 눌러야 성공했습니다(실패 기록 1). HE 전에 원인 확인이 필요합니다.
