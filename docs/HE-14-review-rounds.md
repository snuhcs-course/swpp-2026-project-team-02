# HE-14 — Repeat the agent allocation as review rounds

## Finding and agreed behavior

The evaluator feedback raised a concern that generated plans could leave substantial study availability unused. The requested behavior was to honor the agent's primary topic-minute allocation, then use remaining capacity for complete repetitions of that allocation as review when it fits. If another complete round does not fit, keep the remainder as spare time rather than padding or partially repeating a round.

The requester clarified the count as:

```text
total rounds = floor(total usable availability / agent primary allocation minutes)
review rounds = total rounds - 1
remaining capacity = spare time
```

For example, with 8,100 usable minutes and a 685-minute primary allocation, 11 total rounds fit: one primary round plus 10 review rounds. The remaining 565 minutes stay unused.

## Implementation

- The Agent is asked to return only the primary evidence-based topic allocation. It is instructed not to pad the allocation with extra review minutes.
- The application-side scheduler repeats the accepted topic-minute mix only in complete rounds. It uses remaining daily capacity, preferring dates already used for the topic and then nearby dates; it stops if a complete round cannot fit.
- The output records agent-requested minutes and added review minutes. The user-facing summary reports the review time and says when capacity remains spare.
- The Agent prompt also asks it to keep each topic's study time in contiguous blocks where practical, favor nearby dates when a topic spans multiple days, and balance weekly load without fragmenting topics needlessly. Busy periods and availability gaps may still split a topic block.

Implementation is in `backend/license_planner/agent.py`, `backend/license_planner/scheduler.py`, and `backend/license_planner/tools.py`. The change was committed in `7341607` (`Implement review rounds for HE-14`).
