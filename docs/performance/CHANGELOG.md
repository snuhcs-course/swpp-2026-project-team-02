- 성공 77회의 지표를 원본 측정기로 재계산해 대조, 차이 없음
- 원본 미확인 제한을 제거하고 실제 누락을 backend 소스·접근권한 등으로 한정

- 실패 포함 지연, p95, 총 모델 요청 수, 단계별 누적 시간 추가

- 과거 offline 1개 실패와 2개 합성 테스트 소스 누락을 별도 명시
