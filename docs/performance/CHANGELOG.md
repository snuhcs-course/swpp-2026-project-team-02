## 기존 보완 기록

- 화면 전사 대신 원본 85행과 원시 응답을 기준으로 결과 확정
- 성공 77회의 지표를 원본 측정기로 재계산해 대조, 차이 없음
- 원본 미확인 제한을 제거하고 실제 누락을 backend 소스·접근권한 등으로 한정
- 실험 시각을 manifest에 따라 10월 15일 새벽 KST로 정정; 10월 14일 offline 단계 구분
- 성공 77회 모두 제약 통과, 실패 8회 모두 502·6회 요청·단계 초과 확인
- AllCorrect·AllWrong와 예외 케이스의 빠졌던 평균 및 유효 n 추가
- 실패 포함 지연, p95, 총 모델 요청 수, 단계별 누적 시간 추가
- tiny capacity 1분과 3과목 양의 정수 분량 조건의 불일치 근거 추가
- 일부 실패에서 마지막 build가 수용되어도 최종 응답 없이 단계 초과하는 경로 확인
- 모델 분류 기반 r과 고정 분류 기반 r이 다른 10회 및 대표 수치 반영
- 실제 17개 case_id, 원본 입력 해시, 표준 라이브러리 의존성, 재현 도우미 확정
- 과거 offline 1개 실패와 2개 합성 테스트 소스 누락을 별도 명시
